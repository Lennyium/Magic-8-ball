# 🎱 Magic 8 Ball (Python)

A simple and fun command-line Python program that mimics the classic Magic 8 Ball toy. Ask it any yes/no question and receive a mystical answer.

## 💡 Features

- Randomized responses to simulate the Magic 8 Ball
- Personalized question and answer format
- Clear input handling for names and questions

## 🛠️ Requirements

- Python 3.x

## 🚀 How to Run

1. Clone or download the repository.
2. Run the Python script:

```bash
python magic8ball.py
